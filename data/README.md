# data/

Everything in this folder except `benchmark/` is downloaded or generated and is git-ignored.

```
data/
├── fracsim/
│   ├── gaussians/<object>/      10 3DGS reconstructions (download, ~220 MB)
│   ├── renders/<object>/        multi-view images used to train the 3DGS models (optional download)
│   ├── sweep_configs/           generated by tools/fracsim/gen_sweep_configs_with_material_property.py
│   └── sim_output/<run>/        FracSim outputs (RGB frames + physics maps per run)
├── fracgen/
│   └── <split>/                 processed training data: metadata.csv + mp4 folders (download)
└── benchmark/                   benchmark inputs (images + annotations, committed)
```

## Download

```bash
pip install -U huggingface_hub
# 3DGS reconstructions of the 10 objects
hf download Tung11/FracGen --repo-type dataset --include "fracsim/gaussians/*" --local-dir data/
```

Objects: `bread`, `bread_roll`, `cake`, `croissant`, `muffin` (bread-like) and
`rubber_toy`, `rubber1`, `rubber2`, `rubber3`, `rubber4` (rubber-like).
Each `gaussians/<object>/` folder holds `point_cloud/iteration_30000/point_cloud.ply`,
`cameras.json` and `cfg_args`.

See the main README, Section 1, for how to simulate these objects or reconstruct new ones.
